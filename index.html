3D 智能装箱模拟器 & 交互式排布系统

这是一个 100% 运行在客户端、支持离线的高性能 3D 装箱配载和排布规划系统，采用 Three.js 进行逼真的 3D 渲染，并借助多核 Web Workers 并发运行核心算法。

⚡ 核心功能：
  • 多核并行装箱引擎：在后台拉起与您的 CPU 逻辑核心数匹配的 Web Workers（最高 8 线程）并发寻优，页面完全不卡顿。
  • 混合启发式与回溯算法：基于 DFS（深度优先回溯）的 2D 划分算法与基于接触面积最大化、高度-深度评分的 3D 贪婪摆放算法相结合，并支持重力稳定性校验（底部接触面积须 ≥ 50%）。
  • 容器姿态自动优化：计算时自动尝试不同的容器倾斜/旋转朝向（如长宽高调换），找到能装入最多货物的最优摆放姿态，并在最终 3D 渲染时自动映射回您输入的原始长宽高，确保物理表现的一致性。
  • 双模式三维工作区：
    • 自动模式：提供带时间轴进度条的分步动画回放，清晰查看装箱顺序。
    • 手动模式：使用 3D Gizmo 控制器自由拖拽、旋转货物，具备 1cm 网格吸附、重力下落辅助、实时碰撞与溢出检测。
  • 现代视觉与无障碍：完美支持日间/夜间双主题，高对比度设计，界面顺滑且符合 Web WCAG 视觉标准。
📐 核心计算公式：
计费体积重量 (Dimensional Weight)：
计费体积重量 (kg) = (长(cm) × 宽(cm) × 高(cm)) / 泡货系数
重力稳定性支撑率 (Support Ratio)：
支撑率 = (与下方物品重叠面积和) / 物品底面积 ≥ 50%

3D Packing Simulator & Interactive Layout System

A high-performance, client-side 3D bin packing visualization system built using Three.js and parallel multi-core Web Workers. It runs 100% offline in your browser without any backend dependencies.

⚡ Key Features:
  • Multi-Core Parallel Packer: Spawns background Web Workers mapped to your hardware threads (up to 8) to calculate packing solutions concurrently without UI freezes.
  • Hybrid Backtracking & Heuristics: Utilizes a DFS-based 2D layer backtracking solver paired with 3D multi-start greedy scoring. Validates physical placement with real-time bottom support ratio checking (≥ 50%).
  • Orientation Auto-Optimization: Dynamically tests alternative container aspect ratio rotations during computation under gravity limits, matching the best orientation, and transparently maps results back to your inputs for display.
  • Dual-Mode 3D Workspace:
    • Auto Mode: Renders the optimal layout automatically and provides a step-by-step playback controller (Timeline Slider).
    • Manual Mode: Drag, drop and rotate items manually using 3D Transform Gizmos with 1cm snapping, gravity drop, and live collision/overflow checking.
  • Premium Aesthetics & Contrast: Fully responsive glassmorphism interface with high contrast Day/Night theme toggles conforming to accessibility principles.
📐 Core Formulas:
Dimensional Weight:
Dimensional Weight (kg) = (L(cm) × W(cm) × H(cm)) / Volumetric Divisor
Gravity Support Validation:
Support Ratio = (Overlap Area with bottom items) / Base Area of Item ≥ 50%
